# API Reference

This TypeDoc output focuses on the reusable pieces that make the performance comparison measurable and repeatable:

- deterministic portfolio data generation
- filtering, sorting, summary, and formatting helpers
- React Profiler and Performance API helpers
- persistent theme state
- debounced search behavior
- virtual table window math
- benchmark panel and optimized virtual table APIs

It intentionally avoids documenting every small React component so the API reference stays useful as a performance engineering artifact.
